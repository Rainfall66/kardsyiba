    游戏规则

    系统从 1590 张卡牌中随机选一张作为答案,你输入卡名,每次猜测会新增一行,逐属性给出反馈。

    反馈颜色

    • 绿色(命中) —— 国籍、类型、稀有度、卡包与答案相同
    • 黄色(接近) —— 费用相差 1 以内
    • 灰色 —— 与答案差距较大,或该属性为未知("-")
    • 箭头 —— 费用提示答案更高(▲)/更低(▼)

    属性说明

    • 国籍:苏联 / 美国 / 日本 / 德国 / 英国 / 法国 / 意大利 / 波兰 / 芬兰 / 澳新军团
    • 费用:部署费用,0~12
    • 类型:步兵 / 坦克 / 火炮 / 战斗机 / 轰炸机 / 指令 / 反制
    • 稀有度:标准 / 特殊 / 限定 / 精英,以及衍生卡(对局中召唤 / 生成的牌,统一标为「衍生卡」)
    • 卡包:基础 / 战火世界 / 突破 / 忠诚 / 血与铁 / 秘密行动 / 战区 / 冬季战争 / 海战 / 国土阵线 / 战友 / 军团 / 澳新风暴,另有衍生(衍生牌专用)

    单位别名(三位数字速查)

    每张单位卡都有一个三位数字别名,可以直接输入(不必敲中文卡名),也可以用来联想:

    • 第 1 位 = 费用,第 2 位 = 攻击力,第 3 位 = 防御力;例:3 费 2/4 的卡别名是 324;
    • 0 费单位保留前导 0:0 费 1/2 → 012;
    • 指令与反制没有攻防,没有别名;
    • 费用大于 10 的单位不设别名(如 12 费的虎王坦克、鼠式坦克);
    • 攻击力或防御力达到 10 的单位也不设别名(如戈登高地人团防御 10)。

    三位数字不足以唯一标识所有单位,同一别名可能对应几十张卡(如 334 有 36 张)。 别名撞车时不能直接提交,必须从下方的候选条里点选;候选条可滚动,也支持 ↑↓ 键选择。

    复合搜索

    用空格分隔多个词,可以按字段组合筛选(各词分别匹配不同字段,全部满足才列出):

    • 别名 + 国家:334 德国 —— 别名 334 且是德国卡(写作 德国 334 效果相同,顺序无关);
    • 别名 + 类型:334 坦克;
    • 三词复合:334 德国 坦克;
    • 还能加稀有度:坦克 德国 精英。

    可识别的字段词:

    • 国籍:苏联 / 美国 / 日本 / 德国 / 英国 / 法国 / 意大利 / 波兰 / 芬兰 / 澳新军团(可用简称:苏 美 日 德 英 法 意 波 芬 澳)
    • 类型:步兵 / 坦克 / 火炮 / 战斗机 / 轰炸机 / 指令 / 反制(可用简称:步 炮 战斗 轰炸)
    • 稀有度:标准 / 特殊 / 限定 / 精英 / 衍生卡(可用:衍生)
    • 其它词按卡名 / 别名子串匹配

    复合查询只用来缩小候选,不能直接提交(它不是卡名);请从候选条里点选具体卡牌。 候选条顶部会标出识别到的字段词,如 [德国 + 坦克] 匹配 4 张。

    不参与猜测的卡

    以下卡牌已在生成卡库时排除,不会成为答案、也不会出现在候选里:

    • 天气牌(12 张)—— 澳新风暴天气机制的衍生牌(蓝天 / 暴雨 / 雷暴 / 热浪 / 季风雨 等);
    • 老兵升级形态(44 张)—— 与本体卡同名同属性、仅卡包不同,猜起来只有「卡包」一列有区别。

    其余 73 张衍生牌已纳入卡池,稀有度统一显示为「衍生卡」; 同名衍生牌用费用区分(如 惩戒(0费) … 惩戒(12费))。 触发天气的「预报」正规卡(海岸观察员、美国气象局等 11 张)也保留在卡池中。

    胜负

    卡名猜对即胜;8 次仍未猜中或主动查看答案则失败。

    卡池模式

    开始页可选择系统抽答案的卡池,选完即生效,可随时回首页更换:

    • 仅现役 —— 只从现役卡池抽答案,即当前能在天梯 / 休闲模式使用的卡;
    • 仅预备 —— 只从预备卡池抽答案,即已退役、只能在经典模式使用的卡,难度更高;
    • 全部卡池 —— 两者混在一起抽,卡名最全,但同名近似的卡也最多。

    卡池只影响「抽哪张当答案」,不影响判定规则;候选列表始终显示所选卡池内的卡。
