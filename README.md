# K一把 · KARDS卡牌猜测游戏(单机版)

> **非官方粉丝作品** —— 与 KARDS 及其开发 / 发行方(1939 Games)无关。
> 猜卡牌类 Wordle 玩法:输入卡名,根据逐属性颜色反馈,8 次机会内猜出目标卡牌。

纯静态、零依赖、双击即玩:浏览器打开 `index.html` 就能玩,无需 Node / 数据库 / 联网。

**当前收录 1590 张可猜卡牌**(全卡表;含 73 张衍生牌、563 张预备卡池卡牌)。

```
├── index.html      # 入口(开始页 / 卡池选择 / 游戏页 / 规则与结算弹窗)
├── app.js          # 全部逻辑:卡池模式 / 选目标 / 判定 / 补全 / 棋盘 / 存档
├── search.js       # 搜索逻辑(纯函数:词元解析 + 复合 AND 查询)
├── cards.js        # 卡牌数据库(生成产物,1590 张,请勿手改)
├── style.css       # 样式(二战军绿 + 黄铜主题)
├── images/         # 卡图目录(可选,不纳入版本控制;游戏不依赖)
└── LICENSE         # AGPL-3.0
```

## 本地运行

```bash
# 方法1:直接双击 index.html
# 方法2:本地起个静态服务(可选,效果一样)
python3 -m http.server 8080    # 然后访问 http://localhost:8080/
```

## 玩法

- **开始页先选卡池模式**(决定系统从哪个卡池抽答案,详见下节):
  **仅现役 1027 张** / **仅预备 563 张** / **全部卡池 1590 张**;
- 输入卡名(带自动补全),每次猜测新增一行逐属性反馈;
- **单位卡可用三位数字别名快速输入**(费用+攻击力+防御力,如 3 费 2/4 → `324`),详见「单位别名」;
- **支持复合搜索**:`334 德国 坦克`、`坦克 德 精英`,详见「搜索」;
- 🟩 **绿色(命中)** —— 国籍 / 类型 / 稀有度 / 卡包与答案相同
- 🟨 **黄色(接近)** —— 费用相差 1 以内
- ▲▼ **箭头** —— 费用提示答案更高 / 更低
- ➖ **"-"** —— 未知属性,对比按灰色处理
- 8 次机会内猜中卡名即胜;战绩与最近答案保存在本机浏览器(localStorage)

## 棋盘列(属性类别)

| 列 | 判定方式 | 取值 |
|---|---|---|
| 国籍 | 精确 | 苏联 / 美国 / 日本 / 德国 / 英国 / 法国 / 意大利 / 波兰 / 芬兰 / 澳新军团 |
| 费用 | 数值(±1 黄,箭头指方向) | 0~12 |
| 类型 | 精确 | 步兵 / 坦克 / 火炮 / 战斗机 / 轰炸机 / 指令 / 反制 |
| 稀有度 | 精确 | 标准 / 特殊 / 限定 / 精英 / **衍生卡** |
| 卡包 | 精确 | 基础 / 世纪大战 / 突破 / 忠诚 / 血与铁 / 秘密行动 / 战区 / 冬季战争 / 海战 / 国土阵线 / 战友 / 军团 / 澳新风暴 / **衍生** |

卡包译名一律对齐 [KARDS 官方简体中文扩展页](https://www.kards.com/zh/expansions)
(其中 `BloodAndIron` = **血与铁**、`Homefront` = **国土阵线**、`BrothersInArms` = **战友**,
均非字面直译的「铁血 / 家园战线 / 兄弟连」)。

想增删列:改 `app.js` 里的 `compare()` + `COLUMNS`,与 `index.html` 的 `<th>` 三处保持一致即可。

## 卡池模式(开始页选择)

开始页有一个三选一的分段控件,决定**系统从哪个卡池抽答案**(默认「全部卡池」):

| 模式 | 张数 | 含义 |
|---|---|---|
| **仅现役** | 1027 | 只抽现役卡池,即当前能在天梯 / 休闲模式使用的卡 |
| **仅预备** | 563 | 只抽预备卡池,即已退役、仅在经典模式可用的卡 |
| **全部卡池** | 1590 | 现役 + 预备全卡表 |

张数由 `cards.js` 实时统计后写入界面,改卡库后无需手改文案。

实现要点:

- 卡池只影响**抽哪张当答案**,不影响判定规则;候选列表(自动补全)也只在所选卡池内检索,
  并额外拦截「输入了本局卡池之外的卡名」的提交(否则等于白送一次机会);
- 卡池在**开局时快照固定**,打到一半回首页换模式不会影响进行中的对局;
- 选择结果存在 `localStorage`(`kards-yiba:pool`),刷新页面后保持;若存的卡池已失效则回退到「全部卡池」;
- 无障碍:容器是 `role="radiogroup"`,按钮为 `role="radio"` + `aria-checked`,支持 ← → 方向键切换;
- 想增删卡池:改 `app.js` 顶部的 `POOLS` 数组(每项含 `id` / `label` / `note` / `filter`),
  并在 `index.html` 的 `#pool-seg` 里加对应 `<button data-pool="id">`。

## 单位别名(三位数字速查)

每张**单位卡**(有攻击力与防御力的卡)都带一个三位数字别名:

```
第 1 位 = 费用    第 2 位 = 攻击力    第 3 位 = 防御力
```

| 卡 | 费用 / 攻 / 防 | 别名 |
|---|---|---|
| 第 13 龙骑兵团 | 0 / 1 / 2 | `012`(0 费保留前导 0) |
| 第 1 步兵团 | 1 / 1 / 2 | `112` |
| 第 22 卫队旅 | 2 / 2 / 3 | `223` |
| 飓风 Mk IIc 热带型 | 3 / 3 / 4 | `334` |
| 旋风(海战战斗机) | 6 / 6 / 6 | `666` |

**别名可以直接输入并提交**,不用敲中文卡名(`app.js` 的 `resolveInput()` 同时匹配卡名与别名)。

**不生成别名的情况**(共 684 张无别名):

| 情况 | 张数 | 说明 |
|---|---|---|
| 指令 / 反制 | 675 | 这两类没有攻击力与防御力(含衍生牌里的指令) |
| 费用 > 9 | 8 | **本身有攻防**但第一位放不下:虎王坦克(12 费 10/10)、鼠式坦克、B-29 超级堡垒、IS-2、IS-2 1944、M26 潘兴、B-17F、利奥波德 |
| 攻击或防御 ≥ 10 | 1 | **戈登高地人团**(费用 6 但防御 10),否则位数不齐 |

> ⚠️ **别名不保证唯一**。共生成 **906 张**别名,但只有 **188 个不同取值** ——
> 三位数字的信息量根本不够区分 906 张单位。实测:76 个别名是独一的,
> **112 组发生碰撞、涉及 830 张**,最拥挤的 `334` 一个别名对应 **36 张**不同单位。
>
> 所以别名的定位是**快速联想**而非唯一标识。为此做了两道处理:
>
> **① 歧义别名不允许直接提交**(`resolveInput()` 返回 `alias-ambiguous`)。输入 `334` 直接回车会被拦下,
> 提示「别名 334 对应 37 张卡,请从候选项中点选」并自动展开候选条;只有**唯一命中**的别名
> (如 `012` → 第 13 龙骑兵团)才允许直接提交。卡名精确匹配始终优先。
>
> **② 候选条放宽到 60 条并可滚动**(`SUGGESTION_LIMIT = 60`),`max-height: min(52vh, 420px)`:
> 首项是**吸附顶部的计数徽标**;每行显示 `卡名 · 国籍 · 费用 · 类型 · 稀有度 [· 别名]`;
> ↑↓ 键移动会**自动把选中项滚进可视区**;徽标不参与选中(按 `.suggest-item` 过滤);
> 滚动条做了暗色主题适配。

## 搜索(卡名 / 别名 / 复合查询)

搜索逻辑在**独立的纯逻辑模块** `search.js`(浏览器挂 `window.KARDSYIBA_SEARCH`,node 可直接
`require` 做单测),`app.js` 只负责渲染候选。

### 两种输入形态

**① 自由文本** —— 按「子串包含」匹配卡名或别名:

| 输入 | 效果 |
|---|---|
| `旋风` | 卡名含「旋风」的卡 |
| `334` | 别名含 `334` 的卡(36 张别名 + 1 张卡名里带 334 的) |

**② 复合查询** —— 空格分隔多个词,**各词分别匹配不同字段,全部满足才命中(AND)**:

| 输入 | 含义 | 实测结果 |
|---|---|---|
| `334 德国` | 别名 334 **且** 国籍德国 | 7 张 |
| `德国 334` | 同上(**顺序无关**) | 7 张 |
| `334 坦克` | 别名 334 **且** 类型坦克 | 8 张 |
| `334 德国 坦克` | 三个条件同时满足 | 4 张 |
| `坦克 德国 精英` | 类型 + 国籍 + 稀有度 | 8 张 |

### 可识别的字段词

| 字段 | 写法 |
|---|---|
| **国籍** | `苏联` `美国` `日本` `德国` `英国` `法国` `意大利` `波兰` `芬兰` `澳新军团`,简称 `苏` `美` `日` `德` `英` `法` `意` `波` `芬` `澳` `澳新`,英文 `soviet` `usa` `japan` `germany` `britain` `france` `italy` `poland` `finland` `anzac` |
| **类型** | `步兵` `坦克` `火炮` `战斗机` `轰炸机` `指令` `反制`,简称 `步` `炮` `战斗` `轰炸`,英文 `infantry` `tank` `artillery` `fighter` `bomber` `order` `counter` |
| **稀有度** | `标准` `特殊` `限定` `精英` `衍生卡`(`衍生`),英文 `standard` `special` `limited` `elite` `token` |
| 其它词 | 一律当「卡名/别名子串」处理 |

### 三条设计取舍

1. **词序无关**:`德国 334` 与 `334 德国` 结果一致 —— 按字段分类而非按位置解析。
2. **卡名精确优先**:某个词若与某张卡的**卡名完全相同**,一律先当卡名处理。
   否则 `标准弹药`、`特殊增援`、`惩戒(0费)` 这些卡名会被稀有度/字段词抢走语义。
3. **复合查询不能直接提交**:它不是卡名,只用来缩小候选;直接回车会提示
   「这是复合搜索,命中 N 张,请从候选项中点选」。单个卡名 / 唯一别名仍可直接提交。

候选条顶部徽标会标出**被识别出的字段词**,如 `[德国 + 坦克] 匹配 4 张 · 可滚动 / 上下键选择`。

## 卡图(可选)

游戏**不依赖卡图**:`images/` 是空的也能正常游玩。把卡图放进去后,会自动多出两个功能:

- **结算弹窗显示答案卡图**;
- **卡图预览**:鼠标悬停棋盘里的「卡名」格、或候选条里的任意一条卡名,就在旁边浮出那张卡的卡图;
  用 ↑↓ 键在候选间移动时预览也跟着走。

卡图的下载方式见 `images/README.md`(脚本在数据流水线目录,不随本仓库发布)。

两点实现上的取舍:

- **文件名必须与卡牌数据里的 `image` 字段一致**,游戏按 `<img src="images/<image>">` 直接引用;
- **任何一次加载失败都会静默关掉这两个功能** —— 这样在线试玩版(不带卡图)既不会显示裂图,
  也不会因为反复悬停而刷出一堆 404 请求。

## 数据说明

本仓库只包含**游戏运行所需的成果数据** `cards.js`(1590 张)。卡表来源与生成方式:

- 数据**直连 KARDS 官方 GraphQL 接口**(`herokuapi.kards.com/graphql`)抓取,**版权归 1939 Games 所有**,
  此处仅用于粉丝向非商业交流;
- 抓取与生成脚本、原始/中间数据(约 3.5 MB JSON)存放在**数据流水线目录** `kardsyiba-pipeline/`,
  不随本仓库发布;需要更新卡表或查看字段细节时见该目录的 `README.md`;
- 生成规则概要:枚举译中文、纳入衍生牌(稀有度统一标「衍生卡」)、排除天气牌与老兵升级形态、
  同名衍生牌按费用消歧、给单位卡生成三位数字别名;
- **卡图同样不随本仓库发布**(`.gitignore` 已忽略 `images/*.avif`):全量约 48 MB,
  且游戏按设计不依赖卡图。
